# 风行

辐光光球（预制体 `Radiant Orb`，FSM `Orb Control`）改动。

原版时序：`Init` → `Chase Hero`（0.5s）→ `Chase Hero 2` → 撞到东西就 `Impact` 爆开。
实测进相位二后 0.006~0.17s 就炸，`2.25s` 的兜底消散几乎不触发。

本 mod 做两件事：

1. **自定义寿命**：`ChaseHeroWait`（进相位二的延迟）+ `DissipateWait`（相位二兜底）。
2. **撞到玩家/地形不引爆**：把 `Chase Hero 2` 里两个触发器的层号改成 99。
   层 20 = Hero Box（玩家）、层 8 = Terrain（地形），可分别开关。

光球部分是原位改字段值，不增删状态/动作/转移。

生效范围：所有生成该预制体的地方 —— 神居 `GG_Radiance`（P1/P2/P4 全阶段）和普通辐光战
`Dream_Final_Boss`。P4 终极光球身上额外挂的 `Final Control` 不受影响，它的存活由矩形判定决定。

## 神居隐藏房间

在 `GG_Workshop` 的辐光雕像房间右墙，靠近地面用骨钉攻击即可打开入口。沿通道步行到新的神居房间；房间内部范围为 x=302..319、y=35..47，地面与雕像房间齐平（世界 y=35）。地面与房间外壳由风行运行时创建；原生预加载用于雕像和装饰资源。

可沿原路返回；通常重进场景时隐藏墙恢复。从小房间雕像的挑战返回时，会先重建并打开房间与通道，再将玩家放在新雕像前。关闭风行总开关会还原原墙、碰撞与网格；若玩家在新增区域，会先移回辐光雕像房间地面，避免卡墙。其他原场景区域不移动玩家。

此功能不改 `GG_Radiance` 战斗场景，不依赖风行皮肤，也不添加存档、椅子或奖励。隐藏墙沿用神居原版的四次骨钉反馈、受击/破墙音效与玩家击退。隐藏房间复制了完整辐光雕像及其 Inspect 界面、返回门和相机锁，保留原先复制的 57 个静态装饰渲染节点，并补入遗漏的原生拱门片，共 58 个；新增片段的中心放在世界 X=303.5、贴近房间左墙内侧。雕像主体贴图取自原房间独立摆放的原生雕像渲染源，绑定到克隆雕像的显隐节点；同时补回原房间的金色 haze 与黑色渐变背景效果。背景模糊使用独立的原生 BlurPlane 副本，覆盖新房间范围并随房间开关加入/退出原生模糊管线；私有雕像的 Inspect 相机锁固定在新房间中心，Inspect 观察高度恢复原版向上取景，不改原雕像相机。克隆雕像保持常亮，原版首次显现与靠近/离开淡隐逻辑仅在该私有克隆上停用；原雕像行为保持原样。小房间相机锁仍保持原相机Y范围，通道与地形高度不变；隐藏房间雕像的挑战只在本次战斗临时使用 HARD。该挑战胜利或死亡后返回隐藏房间雕像前；若房间或专属门无法建立，则回退到原辐光雕像门。

## 原辐光雕像模式

与 `GG_Workshop` 原辐光雕像交互时，先选择 EASY 或 NORMAL，再选择原版的 Attuned、Ascended 或 Radiant 难度。难度场景、解锁条件与通关记录仍沿用原版；原雕像的模式选择不改写设置页的全局 HardMode。

EASY 保留 P1 原版整块地面、P2 原版七个平台及阶段性地刺，只关闭风行额外的常驻 P1 地刺和 P2 高位地刺。飞剑与其他招式仍照常运行。NORMAL 沿用现有风行普通模式与常驻地刺改动；小房间雕像仍固定为 HARD。全局 HardMode 仅作为其他入口的兼容设置。

原雕像的 EASY/NORMAL 挑战按原生返回流程回到原辐光雕像前。装饰只借用原生 Sprite、材质和内部资源，不克隆装饰业务脚本，也不销毁借用资源。进入新房间、等待稳定以及打开/关闭 Inspect 时，详细渲染探针会自动写入 `ModLog.txt`，无需快捷键。开门快照记录开门瞬间的相机；进入房间并稳定 0.5 秒后的延迟快照用于检查实际取景。背景是否通过 GPU 最终显示，仍需结合新日志和游戏内画面确认。
